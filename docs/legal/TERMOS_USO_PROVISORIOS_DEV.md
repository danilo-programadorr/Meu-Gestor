# Termos de Uso — versão provisória exclusiva para desenvolvimento

Versão técnica: `terms-dev-1.0.0`.

Este texto é um artefato técnico provisório. Não é documento jurídico final, não autoriza publicação e não deve ser usado em produção.

## Escopo do incremento

O ambiente de desenvolvimento permite testar criação de conta, autenticação por email e senha, autenticação Google, recuperação de senha, confirmação de email, perfil básico, consentimentos e encerramento de sessão.

O aceite afirmativo desta versão é necessário para criar o perfil development. As funcionalidades financeiras, integrações bancárias, notificações, inteligência artificial ativa, Analytics ativo e publicação não fazem parte deste incremento.

## Portão de produção

O uso em produção permanece bloqueado até que os Termos de Uso oficiais sejam redigidos, revisados e aprovados, juntamente com a configuração Firebase de produção.
